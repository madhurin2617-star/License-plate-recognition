# 🚗 License Plate Recognition System

A License Plate Recognition System built using Python, OpenCV, and EasyOCR. This project automatically detects vehicle license plates from images and extracts the license plate number using Optical Character Recognition (OCR).

## 📖 Overview

License Plate Recognition (LPR) is a computer vision application that identifies and reads vehicle registration numbers from images or video streams. This project demonstrates how image processing and OCR techniques can be combined to automate vehicle identification.

## ✨ Features

- Detects license plates from vehicle images
- Extracts text using OCR technology
- Simple and easy-to-understand implementation
- Fast image processing with OpenCV
- Supports multiple image formats
- Beginner-friendly computer vision project

## 🛠️ Technologies Used

- Python 3
- OpenCV
- EasyOCR
- NumPy

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/License-Plate-Recognition.git
```

### 2. Navigate to the Project Directory

```bash
cd License-Plate-Recognition
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Usage

Place a vehicle image inside the `images` folder and update the image path in `main.py`.

Run the project:

```bash
python main.py
```

The program will:

1. Load the image.
2. Detect the license plate region.
3. Extract the license plate text.
4. Display the detected result.
